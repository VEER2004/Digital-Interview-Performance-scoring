Problem Definition & Objective
:
Objective:
 
To develop an AI-based system that predicts and scores candidate interview performance using structured interview metrics.
Problem Type:
Supervised Machine Learning
Regression Problem (Predicting continuous performance score)
Business Need:
Reduce human bias
Standardize evaluation
Improve hiring efficiency
Provide scalable assessment system
Data Collection
Dataset Used:

Link: 
https://www.kaggle.com/datasets/maham9/virtual-interview-performance-dataset
Features Include:
Age
Education Score
Technical Questions Answered
Coding Test Score
Behavioural
 Questions Answered
Eye Contact Score
Confidence Score
Speech Speed (WPM)
Filler Words Used
Interviewer Rating
Time Management Score
Round Score
Duration
Network Stability
Target Variable:
Final Interview Performance Score
Data Preprocessing
:
Steps Performed:
Checked missing values
Removed duplicates
Feature consistency check
Converted data types
Correlation analysis
Feature selection
 
Optional Enhancements:
StandardScaler
Outlier detection
Feature engineering (e.g., Communication Index)
Exploratory Data Analysis (EDA)
:
Analysis Done:
Distribution plots
Correlation heatmap
Feature importance insight
Relationship between technical score & final performance
Impact of filler words on performance
Insights Example:
Higher coding score → higher final score
More filler words → lower confidence score
Confidence strongly correlates with interviewer rating

Model Evaluation Metrics:

Performance Categorization Logic
:
After prediction:
Score ≥ 20 → Excellent
Score ≥ 12 → Good
Else → Needs Improvement
This converts regression output into human-readable categories.
